# Draw, explain and hand off: observation protocol

**Status: open.** No human sessions have been run. Automated journeys do not show time saved or
reader comprehension. Do not add editor telemetry.

## Task

Same wording every session: an API accepts an order, a queue holds accepted work, a worker
processes it, and a database records the result.

1. Record revision, platform, input method and prior familiarity.
2. The participant draws the system, explains one order's journey, and hands the diagram to a
   recipient who did not watch.
3. Help only when asked or after a recorded impasse. Do not show **Try an example**.
4. Time: recognizable system, complete explanation, handoff ready, recipient's answer. Exclude
   test-environment problems. Record every request for help.

## Recipient questions

Ask without coaching and score against the system facts:

- Where does this scenario begin?
- Which components hand work to the next?
- What is the final outcome?

Note whether they can advance the story and choose **Make an editable copy** unaided.
