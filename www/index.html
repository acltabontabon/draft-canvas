Shapes that know what they are

One key per shape. The captions write themselves.

Connect a service to a queue and the line says sends command to. Connect it to a database and it says reads / writes. You talk about the system; Draft Canvas handles the captions.

Press ] and it offers the next move in ghost: a worker on that queue, already wired. Tab keeps it. Ignore it and it’s gone.

A lookup table, not a model. No inference, no network. The same shape offers the same move every time.

Walk the room through it

One step at a time

Group the connectors that tell one story into a flow, then present it step by step. Everything else dims but stays in view.

Notes and code pinned to a step show up on that step. Anything still undecided becomes an open point you pick up next meeting.

04

Chapter 04 of 06

Look inside

C4 depth, on one canvas

Keep the overview small. ⌘↓ steps into a shape to draw what’s inside it; ⌘↑ steps back out. The depth map shows where you are.

It knows C4. It never grades you. No validator, no score, no red underlines.

05

Chapter 05 of 06

Throwaway, but exportable

Out to wherever the conversation goes

Most meeting diagrams deserve the bin. The rest should leave cleanly — into a pull request, a doc, a ticket.

A .draftcanvas file is plain JSON with stable bytes. It diffs. It reviews. It belongs in the repo.

  • .draftcanvasThe editable file. Diffable JSON.
  • .dcencThe same, behind a passphrase.
  • PNG · SVGThe picture. An SVG still opens as the diagram.
  • SourceMermaid, PlantUML, C4, Structurizr, draw.io.
  • LinkThe whole diagram in the URL. Nothing uploaded.

Chapter 06 of 06 · desktop app

Your agent sketches in pencil. You ink it.

Claude Code and Cursor draw over MCP

Ask your agent to draw how orders move through the repo. It describes the parts and how they connect — never a coordinate — and Draft Canvas lays it out as an ordinary diagram.

Follow-ups edit the same diagram, one undo step each. Or ask for a proposal: nothing is inked until you press Accept.

Off until you turn it on. Only in the folders you pick. Draft Canvas sends your diagrams nowhere.

Why it exists

Every meeting starts as a scribble.

Draft Canvas turns it into the one picture everyone shares.

On the left, a pencil scribble from a meeting: boxes labelled checkout?, kafka? sqs? and a crossed-out worker, a DB, and retries? Its lines are routed into one connector that arrives at a clean diagram: Orders API sends command to an orders queue, consumed by a Fulfilment worker that writes to Orders DB, with a note saying retries ×5 and a .draftcanvas file tab at the bottom.

Desktop installers aren’t code-signed yet. macOS and Windows warn you the first time — here’s how to get past it.

Local-first, exactly

In the browser, diagrams live in this browser’s storage. Need one protected at rest? Export it as .dcenc.

On the desktop, the file on disk is the storage: plain JSON you can move, diff and back up.

No network calls of its own. A test fails the build on any, and the page’s security policy forbids them. What’s stored, in detail.
