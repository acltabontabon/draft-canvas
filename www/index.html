Installation notes

First install? Installers aren’t code-signed yet. macOS and Windows show a warning — here’s how to open the app. See all releases.

On a Mac with Homebrew

brew install --cask acltabontabon/tap/draft-canvas

Prefer a tab? The browser editor needs no account and works offline once loaded. Diagrams stay in this browser; export the ones you want to keep before clearing site data. Move between browser and desktop with a .draftcanvas file. Privacy details · Self-hosting.
